# Baby Cupid vs the AI Judge

A determined baby Cupid's glowing golden arrow is frozen an instant before it pierces the glowing heart-shaped chip in the chest of a giant chrome robot judge whose eyes are turning into hearts. Baroque cherub painting meets neon cyberpunk, rendered in deep midnight blue with hot pink and gold.

`main.py` copies the committed `entry.jpg` to the output directory as `entry.png`.

## Image Details

The entry image is a 1024x1024 JPEG of 329251 bytes. Repeated runs of the program produce byte-identical output.

## Run it

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
